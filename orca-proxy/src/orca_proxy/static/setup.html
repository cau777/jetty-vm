Jetty setup

Prepare your Jetty gateway

Jetty creates a private LXD network and a gateway VM. Agent VMs use this gateway for web access through the host proxy.

Checking LXD and the proxy…
LXD access grants root level control of this computer.

Your account must be in the lxd group. After Jetty adds it, sign out and back in before continuing. If access is still unavailable, reboot so the background service receives the new group membership.
